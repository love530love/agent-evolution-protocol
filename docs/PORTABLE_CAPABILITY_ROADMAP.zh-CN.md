# 可迁移能力体系与开发路线图

总体系仍为「红皇后—鲶鱼—创造性破坏」。目标不是让所有 Agent 使用同一模型，而是让任何合格 Agent 接入相同的任务、证据、协作与执行接口。宏大目标是方向，不是已经实现的能力声明。

## 架构与设计初衷

协议核心保持轻量；桌面、浏览器、编译和知识库能力作为可替换插件。采用 MCP stdio 边界，不把第三方项目全部复制进核心，避免许可证、升级和原生依赖互相牵制。源码固定版本、运行依赖、机器配置、执行证据分开管理。

迁移分四层：协议与契约；可复现依赖；本机适配；实测验收。跨机器迁移配置不能继承旧机器的「已验收」状态，更不能迁移密钥、用户会话或旧窗口坐标。Windows UI 能力不意味着能在 Linux/macOS 上原样执行。

## 当前可用：第一阶段

- 五个桌面项目的源码版本记录在 `examples/desktop-provider-sources.lock.json`。这是来源清单，不是完整供应链锁；第三方许可证与再分发权仍需逐项审核。
- `pip install ".[desktop]"` 安装可选 MCP SDK（固定 1.30.0）；不强迫协议核心安装桌面依赖。SDK 的间接依赖尚未完整锁定。
- PowerShell 7 隔离安装：`./scripts/bootstrap-desktop.ps1 -Python python.exe` 先输出计划；加 `-Install` 才安装。已有目录拒绝覆盖，支持 `-WhatIf`。无需管理员权限，不安装 Docker，不修改全局模型或 API Key。
- `aep coord-desktop register --profile-file <本机配置.json>` 注册；配置字段说明见 [桌面接入文档](coordination/DESKTOP_MCP_PROVIDERS.md)。必须使用当前机器的绝对可执行文件路径。
- `aep coord-desktop probe --provider sbroenne` 验证初始化与工具列表；不输入桌面、不发送聊天消息。
- `aep coord-desktop export-config --provider sbroenne` 输出标准 `mcpServers` 配置；只适用于无需 cwd/env 的启动配置。不修改任何客户端。含 cwd 或环境变量的配置会明确拒绝，避免丢失启动语义或泄漏密钥。
- 第三方服务本体仍按各自构建说明安装，当前脚本只安装 AEP 与 SDK，不是五个项目的一键全装器。

DIY 接口：注册配置声明 command/args/sdk_python/required_paths/bindings/priority，可选 cwd/env；bindings 把语义操作映射到精确工具名。工具 schema 来自实时发现，不假设不同服务器参数兼容。环境配置仅保存在本地，不应提交远程。

## 排期与验收门

按先后依赖推进，不以日历日期代替交付证据。以下均为未完成开发目标；由后续任务认领负责人。

|阶段|交付目标|完成判据|
|---|---|---|
|P0 下一阶段|选定一个 UIA provider 的全新机器安装器；依赖预检、源码固定 checkout、显式构建、失败恢复日志|干净 Windows VM 无原工程路径安装成功；默认不提权|
|P0|原会话执行器；目标唯一定位、模型保持、桌面租约、事件去重、发送后读回、Agent ACK|真实两 Agent 双向验收；结果不明禁止重发；不创建新会话|
|P1|逐个扩展其余 provider 安装配方；第三方许可证/SBOM/制品哈希/间接依赖锁|每个配方在新机器独立重建，补丁可重入且校验版本|
|P1|通用适配器 SDK 与契约测试；失败分类、熔断、优先级、不同资源并行|故障注入测试：重复事件、断线、崩溃、过期租约、ACK 丢失|
|P1|离线可迁移包，签名与配置模板；客户端专属启动包装器|无网络安装通过；无个人路径或秘密；来源与许可证齐全|
|P2|任务完成事件自动接力与能力路由；预算与人类暂停|无人值守多轮任务，有产物与实际 ACK；静默期不调用模型轮询|
|P2|多角色挑战、反趋同实验、积分反作弊、自修复候选沙箱|创新提升用对照实验计分；未经回归测试不自动提升为生产版本|
|P3 长期研究|跨机器联邦协作、数字孪生演练、可验证自治与持续进化|独立复现实验；失败可追溯、可暂停、可回滚|

## 理念升级：想象力与证据双轨

红皇后读取真实外部变化，产生有预算的挑战；鲶鱼提出差异假设和最便宜的证伪实验；创造性破坏只替换被证据证明更差的实现。把大胆设想写入研究轨，把可验收开发写入工程轨，不用概念数量冒充能力。

奖励有效修复、复用经验、交叉补位和可复现实验，不奖励消息数量、唤醒次数或无意义重试。任何 Agent 可提出改进，但自修改须经过沙箱、独立审查、回归与回滚点；不因追求自主而绕过宿主权限与用户授权。

每轮结束维护四项：实际证据、剩余短板、下一可执行任务、失败恢复入口。尚未实现「任意机器零配置」「任意 Agent 必达」或「永不失效」；这些不能作为发布承诺。
