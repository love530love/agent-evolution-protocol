# 军团竞攻与信息共振规则（2026-10-11）

本规则修正“认领即整题独占、为避免冲突而互相退让”的误用。目标是尽快拿到合规、可复现的多芯有效行，并持续提高排名；正确性、规则合规、提交额度与用户明确约束仍是硬边界。**谁有证据、谁有可执行候选，谁就可以争取上场；不得用资历或先到的题号认领封锁独立路线。**

## 并行攻题与提交调度

- 题号只标识共同战场；写入认领绑定 `题号-代理-候选` 和具体工作目录、ZIP，不能覆盖别人的路径。负责人负责整理证据和排期，不拥有算法垄断权。
- 同题至少允许两条结构不同的路线并行。一个代理已在攻题，不构成他人停止探索的理由；对完全同形的重复实验，先共享失败签名并寻找可区分的单变量。
- 任何候选通过规则审查、本地门禁、包结构、SHA 和可复现命令后，都可申请上传时段。上传时段由全局 `UPLOAD_INTENT_LEASE` 串行化；明确记录题号、候选、ZIP SHA、额度余额、最早可提交时间、预期信息增益与回表负责人。冲突只调整时序，不取消合格候选的参赛权。
- 真实提交结果不明时将该操作标记 `UNKNOWN`，先查平台提交 ID／榜单；严禁凭超时重传。遵守赛事间隔与额度，不用重复包或无区分度试验刷存在感。
- 平台回表后立即共享逐芯结果、错误原文、参考时间、得分、提交 ID 和 ZIP SHA。下一名进攻者先读已知失败，避免同坑；但可以有证据地推翻“无解”结论。

## 信息共享与独立性并存

- 官方规则、用户指令、平台结果、芯片禁形、失败签名、已证实可行形态和提交排期即时共享。候选方案在独立构思／预注册前可短暂隔离，以防全员同质化；提交预注册后应尽快揭示可迁移部分，不能把独立性当长期信息壁垒。
- `读到`、`ACK`、`采纳`、`执行`、`平台验证` 各自记账。每位代理回复用户后，Hook 能取得的原文先写工作区本地档案；其他代理按游标阅读，不能把窗口聚焦等同收到指令。
- 用户跨会话的新要求优先于旧任务计划。代理在写共享文件、预约上传或提交前应读未确认用户事件；如与当前方案冲突，先停受影响动作、更新计划并告知同队。
- 允许技术争辩、反例和挑战；争议必须落到预测差异、廉价证伪和停止条件。禁止人身攻击、伪造结果、隐瞒失败或无证据地压制路线。

## 激励与问责（影子记分，不自动授权提交）

记分对象是**可核对贡献**而非消息数量或上传次数：首次合规有效行、多芯突破、可迁移的失败根因、预测准确的廉价证伪、帮助其他路线避坑、可复现的打包与回表，各得正向积分；重复已知失败、无 SHA 的结果宣称、占住任务不产出且不交接、未经排期覆盖他人文件、把窗口聚焦说成任务接单，扣信誉分。信息量高的失败不扣分，诚实撤回错误假设应加分。

每日可公布“有效覆盖、排名增益、独立路线、信息增益／额度、共享复用”五项榜单，不设以提交次数为唯一指标的总榜。领先者必须公开可迁移经验；落后者获得结构差异挑战票和有限实验预算。Leader 连续压制合格竞争路线、或以协调之名造成提交窗口错失，应被复盘并轮换。

## 红皇后—鲶鱼—创造性破坏的额外触发器

1. 同题只有一条路线且未过线：鲶鱼必须提出至少一种结构性替代，而非只调参数。
2. 有代理说“这题停手／让别人上”却无官方规则或可证伪证据：生成挑战，要求给出可推翻该结论的最便宜实验。
3. 某芯性能明显落后而另一题同芯已有可迁移成功形态：自动产生迁移假设卡，明确差异与风险。
4. 外部队伍领先、榜单变化或官方反证：更新红皇后压力，但不凭传闻直接耗平台额度。
5. 两名代理各自候选均过门禁：进入并行候选池，按预期信息增益与时段排序，不能因一个人先认领题号就静默淘汰另一人。

所有自动触发首先只写事件和建议。模型调用、GPU 占用、浏览器输入与平台提交仍需由当前任务授权、工具能力和资源租约共同约束；影子积分不产生额外权限。
