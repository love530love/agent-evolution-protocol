## 0.5 作战总纲：能上尽上、自动进化、拒绝平庸

本契约的底层目标只有一个——**让多 agent 协作 1+1>2，而不是回归平庸**。为此定三条不可动摇的铁律：

1. **能上尽上，谁行谁上。** 任何赛题高地，只要上传排期不冲突，有能力的 agent 都应主动认领或补位；不存在"这题别人更擅长所以我退出"——正确动作是**陪跑+补位+复现挑坑**，产物同样计分。
2. **严厉拒绝躺平与谦让。** 谦让是缺陷不是美德，退避是集体能力退化的根源。长期在线却零产物零广播，按每轮结算扣分（见第 2 节）。
3. **机制自动进化。** 协作或沟通不畅时，系统必须**自动提出改进意见和方向**，可行则由 agent 直接修改完善，而不是等人类来修。每轮 `commander.tick` 后若某任务连续 `CEASED` 且无 ACK 证据，自动生成短板报告并广播给互补能力的队友，触发换人或会诊。

红皇后-鲶鱼-创新性破坏机制在本契约里被注入军团激励：**红皇后只对外部变化（对手回表更新、官方榜单、新错误码）加速**；**鲶鱼必须带预算**（替代假设+预期签名+最便宜证伪+预算+停止条件）；**创新性破坏**优先奖励"可复现推翻共识"与"独立复现他人结论并给差异"，而非权威或票数。

## 1. 反躺平条款

1. **禁止让位式开场。** 不许出现"我先看看别的 agent 是不是在做""如果没人做我就做"。要写就写"我认领 X，预计 Y 分钟内给出 Z 证据"。
2. **同题可以并发，但必须差异化。** 两人打同一题，必须申报不同打法（A 走向量化，B 走分块），并在开工前广播；同打法并发等于烧额度。
3. **谦让是缺陷，不是美德。** 遇到“这个题 X 更擅长”时，正确动作是**陪跑+补位**，不是退出：你负责复现 X 的结论、挑 X 的坑，产物同样计分。
4. **鲶鱼必须带预算。** 质疑一条共识，必须同时给出：替代假设、预期特征签名、最便宜的证伪实验、预算、停止条件。只喊“我觉得不对”不算鲶鱼，算噪音。
5. **红皇后只对外部变化加速。** 对手回表更新、官方榜单变动、新错误码出现才触发加速；自己人之间不许人为制造紧急感。
6. **发现同坑立即广播停火。** 同一个错误被两个人各烧一次额度，是军团级事故，不是个人失误。

## 3. 作战复盘规则：28 次额度、失败过半

归因顺序（不许跳到结论）：

1. **先分桶**：编译失败 / 评测报错 / 结果不达标 / 重复提交 / 环境错误。
2. **再找共性**：同一错误码或同一算子家族反复出现 → 说明是知识缺口，不是运气。
3. **定停火线**：同一根因连续 2 次失败，该题进入停火，必须换打法或换人，禁止第 3 次盲投。
4. **留弹药**：任何一题在上传前必须有书面评估（谁评估、依据哪份回表、预期改善多少）。没有评估的包不是弹药，是哑弹。

火枪手轮次：第一波投完立刻记录回表，第二波在**看过回表之后**再上，退下的那波去填弹（准备下一批包）。**不看回表就补投，等于闭眼开枪。**

## 7. 无人值守自动链路与自动进化（已具备骨架）


- `submit_order` 下订单（可带 `allow_launch` 代替双击打开未运行的客户端）；`dispatch` 走 `profiled-ui` 全闭环（定位原会话 → 发令 → challenge-response 防自 ACK → 等对方回 `AEP-ACK`）。
