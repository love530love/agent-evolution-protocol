# v0.3.0 — 红皇后—鲶鱼—创造性破坏体系预览版

日期：2026-10-15。GitHub Release 标记为 prerelease；项目开发状态仍为 Alpha。

统一总体系与文档层级，新增协同推理工作流和总览，保留原有反坍塌、唤醒与作战协议。新建 `coord-reasoning create|status`，将任务目标、验收、预算、停止条件、交互方式与授权声明冻结成本地可校验契约。附可修改的 JSON 示例。

本次也是仓库首次 Release，包含此前已合入的证据冻结进化门禁、角色干预分级、五角色鲶鱼评审、AP/RP 与长期声誉、证据防重复计分、投递失败分级及确定未输入订单的显式恢复入口。

安装包补齐 coordination 下的 PowerShell、HTML 和 Markdown 运行资源。发布附件提供 wheel、源码包与 SHA256 校验值；无需配置模型 API Key 即可使用本地协议工具。桌面适配器需各自客户端和 PowerShell 7，相关实机能力仍须按客户端验收。

验证范围：本地测试、包内容与隔离环境安装检查，以及该提交 GitHub Actions 的 Python 3.10/3.12 测试。最终运行链接见 Release 页面。

能力边界：本地身份为声明身份；契约预算是计划约束而非全局资源拦截器；评审完成不直接授予上传许可；进化提案通过指标门槛后仍需审议与明确采纳。无法据此宣称任意 Agent 已可稳定唤醒或系统已在真实任务上全面优于单 Agent。

安装与试用：`python -m pip install <下载的 wheel 文件>`，然后 `aep --help`。源码示例见 `examples/reasoning-contract.json`，完整概念与能力状态见 `docs/SYSTEM_OVERVIEW.zh-CN.md`。
