# v0.6.1 — 说清楚窗口为什么驱动不了

发布日期：2026-10-31
上一版：`v0.6.0`（问系统，而不是猜像素）

## 背景

客户端以管理员运行是**有意的选择**：Agent 自己执行命令时，非提权会被 UAC 卡住，任务就停住。
代价是 Windows 不允许普通权限进程枚举、移动或输入到那个窗口——而且**每一步都是静默失败**。

上一版只会回 `input_found: false`，看不出原因。

## 改了什么

驱动层现在在每个回执里写：

```json
{
  "pid": 22796,
  "target_elevation": "unknown",
  "drivable": false,
  "blocked_by": "TARGET_NEEDS_ELEVATION",
  "hint": "the target runs at a higher integrity level; start the executor elevated, or the client unelevated"
}
```

`unknown` 就是「打不开它的令牌」，等于「权限不够」。能打开时写 `standard`/`elevated` 且 `drivable: true`。

## 操作规则

执行器与客户端**同权限启动**即可，方向是单向的：提权进程能驱动低权限窗口，反之不行。

```powershell
# 管理员终端
aep --coord-root coordination federate serve --interval 30 --agents qoder codex
```

验证：

```powershell
aep coord-a11y status --pid <目标pid>     # 期望 "drivable": true
```

项目在 `K:`，`GetDriveTypeW` 返回 `FIXED`，提权进程可见。若仓库放在网络映射盘，提权后会看不到。
