# v0.4.2｜贡献溯源、风险控制与 Provider 分发门

## 主要变化

- 增加 `CONTRIBUTORS.md`，记录人类维护者与 OpenAI Codex 的 AI 辅助贡献；
- 增加风险登记与控制基线，覆盖许可证、供应链、会话定位、凭据、自动重试和版本漂移；
- 将 Provider Catalog 的默认溯源策略机器化为 `unverified + reference-only`；
- Provider Catalog 在策略被放宽时直接拒绝加载，防止未核验依赖进入发布路径；
- NOTICE 与第三方致谢文档明确上游署名、许可证核验和再分发边界；
- 版本一致性测试与发布包继续保持可回滚。

## 署名边界

OpenAI Codex 的署名表示 AI 辅助贡献来源，不构成独立法律版权主体、商标主张、雇佣关系或上游项目背书。最终发布权和维护责任仍由项目维护者承担。
