# v0.4.0｜持久联邦工作区与桌面主控

本版本把 AEP 从“协作协议与唤醒适配器集合”推进到可恢复的持久联邦工作区控制面。

## 主要能力

- Workspace ID、水印隔离、结构化快照、事件/任务/接力 Schema；
- 每 Agent 独立 MCP Bundle 注册、配置渲染和会话感知派工规划；
- AEP Federation MCP Server：发现、启动、派工、回读和状态查询；
- Desktop Runner：用户交互式 Session 启动预览、窗口/进程身份采集和就绪检测；
- Supervisor ↔ Desktop Runner 持久 IPC：原子写入、幂等、冲突保护和跨重启恢复；
- 桌面主控、无头增强的生产架构与验收清单；
- 诊断 Agent、策略进化 Agent 系统提示词；
- Qoder CN 等桌面 Agent 的原会话锚定基础；
- 本地运行时目录、窗口回执和 Agent memory 默认不进入版本库。
