# v0.3.1 — Windows 桌面 MCP 备用能力层（预览版）

日期：2026-10-16，Alpha/prerelease。

新增 `coord-desktop register|inventory|probe|plan`：可配置启动命令、参数、环境变量、依赖和精确工具映射；实际 MCP stdio 初始化与分页工具发现；有界超时、失败回执及服务端根因 stderr。工具 schema 与本机路径保存在本地协作目录。

Commander 在确定未输入的 `DEFERRED` 回执中附备用定位计划；发送结果不明的 `CEASED` 只提示先核验，不自动切换服务重发。配置变化或过期的工具发现记录不进入计划。

本机实测五个项目均完成协议握手与工具发现：shuyu 48、sbroenne 本机构建版 19、MCPControl 23、Mario 50、CursorTouch 20；另保留 sbroenne v1.3.28 发布版 18 工具。MCPControl 的 keysender 原生插件经本机修复编译，附 MSVC C4596 源码补丁与复盘。确认 Mario 已带 AutoItX DLL，CursorTouch 直接复用现有 Python 3.14 venv。

SDK 可选；核心包不强制依赖桌面服务或模型 API Key。本机使用隔离 MCP SDK 1.30.0；CursorTouch 配置关闭其匿名遥测。服务端环境变量在本机配置中声明。

验证：本地单测/完整 pytest、五项目实际 MCP 工具发现、发布包构建和隔离安装，以及 GitHub Actions Python 3.10/3.12。

此版本交付注册、发现、依赖诊断与计划能力。未调用桌面输入工具；不代表任意 Agent 的原会话投递、回复读回和 ACK 已验收。详见[接入说明](../coordination/DESKTOP_MCP_PROVIDERS.md)与[实机记录](../coordination/DESKTOP_MCP_LOCAL_ACCEPTANCE_20261016.md)。
