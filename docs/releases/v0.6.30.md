# v0.6.30 — 原会话执行面围栏与严格无人值守闭环

## 这一版解决什么

上一版已经把指挥模块分层；这一版收紧的是最容易造成“看上去派工成功、实际消息进入了错误
会话或根本没有送达”的执行面。目标不是把本地 return code 包装成成功，而是让每一条写入都
落在同一原会话围栏内，并把不完整证据诚实地保留为 `DEFERRED`、`UNCERTAIN` 或 `CEASED`。

这仍不是第三方 Agent 的真实接单宣言。完整生产验收依旧是：

```text
定位原会话 → INPUT_SUBMITTED → MESSAGE_VISIBLE → AGENT_ACK → TASK_RESULT_READBACK
```

任何缺环都不能由本版本补成“已完成”。

## 主要变更

### 1. 所有原会话写入共用一个更可靠的 lease

- `federation.locking.workspace_lock` 的可重入范围从“同一进程”收紧为“同一线程”。
  同进程的两个 scheduler 线程现在也会像两个进程一样排队，避免同时向同一聊天窗口输入。
- `external_runner` 对显式 `coordination` 根自动收敛至
  `<coord-root>/session_leases`；未传 `workspace_id` 时从协调根推导，而不是从执行器 CWD
  推导。这样 CLI/external route 与 UIA 不会再因目录不同产生两个 lease。
- 旧 sidecar 仍作为兼容候选读取；未解决的旧记录继续阻断，而不是迁移时静默丢失。

### 2. CDP 从“DOM 直写”升级为原会话受控写入

新增 `coordination/cdp_session_delivery.py`，作为无状态 `transport_cdp` 的上层包装：

1. 要求精确 `target_id`，并验证 WebSocket endpoint 的 `/devtools/page/<id>` 与它匹配；
2. 要求经核对的 `ui_profiles/<agent>.json`、稳定会话 marker 和共享 session provider；
3. 先读 transcript 核验会话与模型，再定位 composer；
4. 获取与 UIA 相同的 session lease 后才允许写入；
5. 只在同一 DOM 中读回 event id 时标为 `MESSAGE_VISIBLE`；目标 Agent 自己的回复仍是
   唯一的 `AGENT_ACK` 证据；
6. `SENDING` 后的任何不完整结果保持 `UNCERTAIN`，禁止自动换通道重发。

`coord-cdp send` 现在必须提供 `--agent` 与 `--target-id`；`scan`、`targets`、`read`
保持只读，不要求先建立协调工作区。`commander` 缺失合格 profile 时直接 `DEFERRED`，不再用
raw UIA/CDP 猜会话。

### 3. 回执不会再被新的失败覆盖

一个旧 event receipt 可能是唯一的取证材料。CDP 发现 receipt 冲突、内容损坏、target 不匹配
或 lease 忙时，保留旧文件，并在同目录写入带 request digest 的 sidecar outcome receipt。这样
排障记录不会因为一次错误重试被改写。

### 4. 调度器的“完成”有严格模式

`federate` 增加：

```powershell
aep federate step --completion-policy unattended-strict ...
```

该策略要求：

- 目标在同事件、同原会话中的 ACK；
- 正向结果回读；
- 结果证据已经核对会话，且没有未知会话歧义。

缺少其中任一事实，任务维持 hold，不会推动下游 DAG。默认仍为 `standard` 以维持兼容性；所以
无人值守部署必须显式选择 `unattended-strict`，不能因为升级包版本就假设严格策略已生效。

### 5. 路由层拒绝“假成功”

`wake_router` 不再把 adapter 的 `{ok:true}`、`sent`、`DELIVERED` 或
`ACKNOWLEDGED` 文本直接升格。只有同事件且已解析原会话的消息可见证据才到 `DELIVERED`；再加
目标生成的同事件 ACK 才到 `ACKNOWLEDGED`。其余状态保留为 `INPUT_SUBMITTED` 或 `UNCERTAIN`。

```powershell

& 'C:\Users\love\.codex\runtimes\python311\Scripts\python.exe' -m agent_evolution_protocol `
  --coord-root coordination coord-cdp scan

& 'C:\Users\love\.codex\runtimes\python311\Scripts\python.exe' -m agent_evolution_protocol `
  --coord-root coordination federate step --workspace <workspace-id> `
  --completion-policy unattended-strict
```

使用既有已发布 tag；不要在工作区执行破坏性 reset。
