# v0.4.1｜执行生态、能力运行时与工程标准

## 主要变化

- 增加第三方执行生态目录，覆盖浏览器、桌面视觉、Windows UIA、终端、工程 Agent、移动端和 REA；
- 增加 `aep coord-provider-catalog` 只读目录命令；
- 增加 Provider L0-L3 接入验收门，禁止把“工具可发现”误报成“Agent 已接单”；
- 增加隔离能力运行时安装器：MCP、Playwright/Chromium、pywinauto、watchdog、OpenTelemetry、DuckDB；
- 建立项目体系、Schema、版本、发布、回滚和第三方溯源规范；
- 增加第三方致谢和再分发政策，未核验许可证的 Provider 保持 reference-only；
- 修正包内版本号与 `pyproject.toml` 的版本漂移。

## 已知边界

第三方 Provider 目录不表示项目已全部安装或通过生产验收。OpenHands、UI-TARS、Skyvern、Browser Use 等仍需按实际任务分别完成 L1-L3；云端模型、账号、Token、登录态和厂商 Agent 原会话不随 AEP 发布。
